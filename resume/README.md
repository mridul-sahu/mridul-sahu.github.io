# Résumé

`resume.html` is the source of truth. Regenerate the PDF the live "Résumé" button serves with:

```sh
npm run resume:pdf
```

This prints `resume.html` with headless Chrome directly to `public/Mridul_Sahu_Resume.pdf`. Commit and push the site to deploy the new version.

`Mridul_Sahu_Resume.pdf.orig-2026-07-10` is a local-only snapshot of the pre-2026-07-13 version (gitignored).
